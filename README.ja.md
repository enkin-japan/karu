# Karu（軽）

[English](README.md) | [简体中文](README.zh-Hans.md) | **日本語**

macOS 向けに、意図的に極小化されたネイティブのプレーンテキストエディタです。
**常駐メモリ約 30 MB、1 秒未満で起動。**

Karu（軽）は、テキストエディタはほとんどコストをかけるべきではないという信念の
もとに作られています。すべての機能は厳格なメモリ予算の審査を通過しなければ
採用されず、収まらない機能は却下されます——軽自動車が軽量であり続けるのは、
ルールでそう定められているからであるのと同じです。

## 機能

- 21 言語のシンタックスハイライト：Markdown、JSON、JSONL、YAML、TOML、Python、
  HTML、CSS、JavaScript、TypeScript、TSX、C、C++、C#、Java、Go、Rust、Swift、
  Bash、SQL、XML（plist ファイルは XML として扱います）。色を付けるのは表示
  されている部分だけです。配色は VS Code の Dark Modern と Light Modern テーマに
  準拠しています。埋め込まれたコードも、それぞれの言語でハイライトされます：
  HTML の `<script>` と `<style>`、Markdown のコードブロック、JSX と TSX
- コードの折りたたみ、行番号、VS Code スタイルのインデントレインボー
- ワンキーで折りたたみ/展開（⌥⌘[ / ⌥⌘]）、全て折りたたみ/展開（⌘K ⌘0 /
  ⌘K ⌘J）、折りたたみ状態は編集後も保持
- 正規表現による検索と置換
- カーソル位置の単語ハイライト、不可視文字・双方向制御文字の警告表示、CSS
  カラー値のインラインスウォッチ
- スコープを考慮した補完候補。各候補の種類を表示し、可能性の高いものから順に
  並べます。ドット（.）の後には直前の値のメンバーを一覧表示し、Python と
  JavaScript/TypeScript では推論した型、C、C++、Swift、Go、Rust、Java、C# では
  宣言された型を使います。import 文の補完にも対応し、Python の仮想環境や
  `node_modules` のモジュールも候補に含まれます
- これらはすべて Karu 自身のプロセス内で動作します。言語サーバーや補助プロセスは
  使わず、Karu がプロジェクトのコードを理解するために、そのコードを実行することも
  ありません
- プロジェクトフォルダ：「設定 › コード › プロジェクトフォルダ…」でフォルダを
  追加すると、Karu がバックグラウンドでインデックスを作成します。以降の補完では
  ほかのファイルのシンボルも使われ、「編集 › ワークスペースシンボル…」（⌘T）で
  その中の任意のシンボルへジャンプできます
- 実行（⌘R、停止は ⌘.）：現在のテキストを、保存済みかどうかにかかわらず単一
  ファイルのプログラムとして実行します。対応言語は Python、JavaScript、
  TypeScript、Bash、C、C++、Swift、Go、Rust、Java、C# です。実行出力はエディタの
  下のパネルに表示され、プログラムはそこに入力した内容を読み取れます。ツール
  チェーンは言語ごとに、「設定 › 実行」で、Karu がインストールするもの
  （Python、Node.js、Go、Temurin JDK、.NET SDK、C/C++ 用の Zig。バージョンは固定で、
  ダウンロード時にチェックサムを検証し、Karu 専用の Application Support フォルダに
  保存）、システムの PATH にあるもの、任意のパスのいずれかを選べます。Karu は
  PATH やシェルの設定を変更しません。Swift と Rust はシステムにインストール済みの
  ツールチェーンを使います
- シンボルへのジャンプ（⌘⇧O）、JSON/JSONL/XML/plist のワンキー整形（⌥⇧F）
- コメントのオン/オフ切り替え（⌘/）、行の移動・複製・削除（⌥↑↓ / ⇧⌥↑↓ /
  ⌘⇧K）、括弧・引用符の自動補完と選択範囲のラップ、対応する括弧のハイライトと
  ジャンプ（⌘⇧\）
- コマンドパレット（⌘⇧P）
- プレーンテキストのみの貼り付け（リッチフォーマットは貼り付け時に除去）
- エンコーディングの自動検出 + フォールバックエンコーディングを指定した手動再読込。
  どのエンコーディングで開いたファイルも、保存時は常に UTF-8 です
- 改行コード（LF/CRLF/CR）の表示と変換
- インデント幅の自動検出、言語別設定に対応
- UI は英語 / 简体中文 / 日本語に対応し、ライブ切り替え可能
- 機能モジュール（ハイライト、補完、整形、実行、型推論、ファイル横断
  インデックス）はそれぞれ個別にオフにでき、オフにすると実行時の状態を解放します
- フォーカスを失った際の自動保存（オプション、デフォルトはオフ）、選択文字数
  カウント、フォントズーム（⌘+ / ⌘- / ⌘0）
- `karu` コマンドラインツール：ターミナルからファイルを開けます
- アプリ内ワンクリックアップデート（Sparkle、v0.7.0 以降）

- メモの番号付きリストに行を挿入すると、後続の同階層の番号を更新します。1 回で取り消せます。
- Python の f-string 内の式や入れ子の書式フィールドを個別にハイライトします。
- 設定 → キーボードショートカット：検索、記録、解除、初期設定への復元とアプリ内競合の検出に対応。メモのグローバルキーも設定できます。

設定からファイル形式の既定アプリを変更し、JSON 形式で設定を書き出し・読み込みできます。同じ種類の拡張子は一緒に変更され、macOS が確認を求める場合があります。曖昧な非テキスト形式は表示しません。バックアップには Karu の設定とショートカットを含み、文書・メモ・セッション・システムの関連付けは含みません。読み込みは設定を置き換え、未保存の項目を初期設定に戻します。

XML/plist の整形では、テキスト値、混在コンテンツ、`xml:space="preserve"` を保持します。「ドキュメントをフォーマット」は、入れ子が 512 階層を超える JSON/XML ドキュメントや、整形結果が元の入力より大幅に大きくなるドキュメントの処理を拒否し、ドキュメントを変更しません。Finder やコマンドラインから開いた場合も、クラッシュ後の下書きを復元します。メモの保存に失敗すると、ウインドウを開いたまま終了を中止するため、再試行や別ファイルへの保存ができます。

Karu で開いた後にファイルが別のプログラムで変更された場合、保存時に確認なしで上書きすることはなく、先に確認します（別名で保存…、上書き、キャンセル）。シンボリックリンク経由で開いたファイルはリンク先に保存され、リンクはそのまま残ります。復元した下書きとディスク上のファイルの両方が変更されている場合、Karu は両方を残し、下書きを別のコピーとして開きます。

## メモリ予算（努力目標ではなく強制項目）

| 指標 | 上限 |
|---|---|
| 空のドキュメント、アイドル時 | 99 MB |
| 1 MB ファイルを開いた状態 | 99 MB |
| 10 MB ファイルを開いた状態 | 99 MB |
| コールドスタート | 1 秒未満 |

メモリに関する 3 行は、既定の 800×600 ウインドウでの `phys_footprint` の値で、
`scripts/mem-benchmark.sh` で計測します（空のドキュメント、1 MB の JSON
ファイル、10 MB の Python ファイル）。`scripts/preflight.sh` はリリース前に毎回
これをテストと一緒に実行し、実際の計測内容を示せない実行は合格として
扱いません。この 3 つ以外のストレス入力、たとえば 1 行だけの 5 MB ファイルでは、
上限を超えることがあります。

以下は意図的に、永久に対象外とします：LSP/言語サーバー、Electron/web view、
重量級のフォーマッタ、プラグインシステム。

## インストール

[Releases](https://github.com/enkin-japan/karu/releases) から公証済みの DMG を
ダウンロードし、Applications にドラッグしてください。

CLI ヘルパー（任意）:

```sh
ln -s /Applications/Karu.app/Contents/Resources/karu /usr/local/bin/karu
```

## ソースからのビルド

必要なのは Swift のみです（コマンドラインツールで可、Xcode は不要）。デプロイ
ターゲットは macOS 13 です。最近のリリースは Apple シリコンの macOS 27 でのみ
ビルド・テストしており、それより古い macOS ではリリースごとの再テストはして
いません。配布する DMG は Apple シリコン（arm64）向けのビルドです。

```sh
swift build                    # デバッグビルド
bash scripts/test.sh           # 全テストを実行
bash scripts/bundle-macos.sh   # → build/Karu.app（ad-hoc 署名の場合は SIGN_IDENTITY=-）
```

`scripts/test.sh` は並列数に上限を設けて `swift test` を実行します。並列数を
無制限にすると、タイミングの影響を受けやすいテストが失敗するためです。一部だけ実行する
場合は `swift test --filter <name>` を使います。
