# Third-party notices

## Visual Studio Code — Dark Modern / Light Modern colour themes

Karu's syntax colours (`HighlightTheme` in `Sources/KaruCore/Highlight/HighlightEngine.swift`) reproduce the token colours of the Dark Modern and Light Modern themes shipped with Visual Studio Code 1.146.0 (`dark_modern.json`, `light_modern.json` and the theme files they include). No theme file is redistributed; only the colour values are used.

Source: <https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults>
